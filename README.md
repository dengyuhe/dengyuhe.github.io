# dengyuhe.github.io

Personal website of Maggie (Yuhe) Deng, served by GitHub Pages at <https://dengyuhe.github.io>.

- `index.html`: the whole site (no build step)
- `assets/`: photo and project figures
- `files/`: CV, thesis and research report (PDF)

To update the CV, replace `files/Maggie_Deng_CV.pdf` with a file of the same name.
